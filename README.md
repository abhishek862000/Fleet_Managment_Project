# Fleet Management Project

Hello! Welcome to my Fleet Management Data Analysis project. 

This project is built to analyze a large, event-based fleet service dataset to uncover cost trends, track vehicle details, and help make data-driven decisions for future fleet investments.

---

## 📊 Dataset Overview
* **Data Size:** 25,000+ rows of event-based service logs
* **Timeline:** 24 months of historical fleet data
* **Scope:** Tracking maintenance costs, vehicle details, and service events

---

## 🗺️ Dashboard Structure & Main Agendas

The Power BI dashboard is split into three main pages, each focusing on a specific business agenda:

### 📑 Page 1: Fleet Overview & Expense Details
* **Agenda:** Create a comprehensive, high-level overview of the entire fleet.
* **Focus:** Visualizing total maintenance expenses, active fleet details, and foundational cost distributions.

### 📑 Page 2: 24-Month Trend & Event Analysis
* **Agenda:** Track how costs and service events change over time.
* **Focus:** A deep dive into the 24-month timeline to analyze yearly cost trends, peak maintenance periods, and event frequency.

### 📑 Page 3: Model Sampling & Predictive Insights
* **Agenda:** Identify which vehicle models are the most profitable and cost-effective for future operations.
* **Focus:** Sampling specific models from the event data to compare their long-term maintenance impact and financial efficiency.

---

## 🛠️ Tech Stack Used
* **SQL:** Used for data extraction, querying specific views (like cost by maintenance), and structuring the raw data.
* **Power BI:** Used for building the data model, writing DAX measures, and creating the 3-page interactive dashboard.
* **Excel / CSV:** Source data management.
